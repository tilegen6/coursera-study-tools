# Coursera Study Tools · 1.8.10

Расширение Chrome/Edge для обработки материалов и тестов Coursera. Независимый проект с читаемым исходным кодом.

## Запуск

1. На `chrome://extensions` загрузите распакованное расширение из папки **extension**. Если оно уже установлено, нажмите ↻ у Coursera Study Tools и обновите вкладку курса.
2. Один раз запустите **Start-Bridge.cmd**. Помощник устанавливает подключение Native Messaging для текущего пользователя; права администратора и API-ключ не нужны.
3. Откройте курс и нажмите **Запустить курс** в блоке на странице. Настройки расширения открываются по **Alt+B**.

Материалы работают без посредника. Для тестов используются уже установленные Node.js и Codex CLI с входом через ChatGPT. Остановленный посредник запускается при первом запросе теста; код подключения вводить не требуется. Состояние подключения и диагностика доступны в **Работа с тестом → Подключение Codex**. **Stop-Bridge.cmd** останавливает только эту установку сервиса.

После обновления приложения Codex его прежний файл может быть удалён. В таком случае повторный запуск **Start-Bridge.cmd** обновит путь к установленной версии; повторный вход через ChatGPT при действительной сессии не требуется. Отсутствующий файл CLI диагностируется отдельно от ошибки входа.

## Что делает бот

- Быстро обрабатывает видео, проверяя отметки завершения на Coursera. Если пакетный способ недоступен, использует плеер; скорость — 1–2×.
- Отмечает чтение и обычные материалы через поддерживаемую кнопку завершения.
- Открывает распознаваемые тесты, получает ответы, заполняет и проверяет поля, отправляет каждую попытку один раз, подтверждает обычный диалог отправки и ждёт результат.
- Продолжает работу после загрузки следующих страниц; **Стоп** отменяет дальнейшие действия.

В 1.8.10 выполненные видео, чтения и обычные материалы учитываются по видимым отметкам Coursera сразу из навигации, без открытия каждой страницы. Тесты с сохранёнными 100% повторно не открываются. При выключенном «Повторять тесты до 100%» достаточно отметки успешного выполнения теста; при включённом режиме бот проверит неизвестную оценку на обложке.

Исправлены переходы между модулями с заголовком h2 и ожидание обновления отметок видео. Обычная перезагрузка того же адреса учитывается по состоянию загрузки Chrome, даже без нового URL. Если плеер или отметка материала не загрузились вовремя, пункт переносится в очередь, а остальные материалы продолжаются. Отмена перехода, смена аккаунта и журнал отправок по-прежнему проверяются.

Поддерживаются маршруты `quiz`, `exam` и распознаваемые тесты `assignment-submission`, включая radio, checkbox и текстовые/числовые вопросы. Для неоднозначной страницы `assignment-submission` сначала проверяется её содержимое. Письменная форма без признаков теста пропускается без заполнения.

В 1.7.1 стандартная обложка `assignment-cover-redesign` с кнопкой `CoverPageActionButton` распознаётся независимо от языка названия: например, «Обзор модуля 3». После открытия по-прежнему проверяется сама форма — письменные задания не заполняются. Тесты, ошибочно помеченные как пропущенные версией 1.7.0, автоматически проверяются ещё раз при восстановлении очереди; новые корректные пропуски повторно не открываются.

Изображения из вопроса или подписанного им блока передаются модели как настоящие вложения с привязкой к номеру вопроса. Поддержан используемый Coursera HTTPS-источник `d3c33hcgiwev3.cloudfront.net/imageAssetProxy.v1/` для PNG/JPEG/WebP. Загрузка ограничена по времени, количеству и объёму; перенаправления и произвольные адреса запрещены. Временные изображения удаляются после ответа. Неподдерживаемые изображения не заменяются догадками.

Лабораторные, программирование, письменные работы, peer-review, Coach и неизвестные задания исключены. Известные отдельные маршруты таких заданий бот не открывает. Они показываются как **Пропущено** и не считаются выполненными. Сохранённые очереди прежних версий переводятся на ту же политику; кнопка проверки очереди не включает исключённые задания снова.

Завершение обработки материалов и тестов не означает завершение курса: Coursera может требовать пропущенные задания.

## Автоподтверждение Кодекса чести

В настройках есть пункт **Автоматически подтверждать Кодекс чести в тестах**. По умолчанию он выключен; выбор сохраняется и действует при следующем запуске из панели или блока на странице. Во время работы переключатель заблокирован — для изменения нажмите **Стоп**.

Включение разрешает боту отмечать распознаваемый флажок Кодекса чести перед отправкой теста, в том числе если флажок появляется после заполнения ответов. Полное имя, подпись, другие согласия и флажки внутри вопросов автоматически не подтверждаются. При требовании имени тест остаётся в очереди **Нужны данные**. Когда опция выключена, так же обрабатывается неподтверждённый флажок Кодекса чести.

## Повторять тесты до 100%

Пункт **Повторять тесты до 100%** включён по умолчанию; выбор сохраняется. Изменить его можно до запуска курса. При оценке ниже 100% бот открывает стандартный разбор ошибок, сохраняет его для следующего решения, возвращается через «Назад» на обложку и начинает новую доступную попытку. Порядок вопросов и вариантов может изменяться, поэтому модель сопоставляет их по тексту и смыслу.

В 1.8.1 исправлен запуск пересдачи при открытом разборе: фоновая кнопка обложки не нажимается, пока окно отзыва не закрыто. В 1.8.2 поддержана кнопка «Продолжить» в стандартном окне «Начать новую попытку?». Одноимённые кнопки других диалогов не нажимаются. Зависшие до этого подтверждения пункты 1.8.0–1.8.1 восстанавливаются однократно; уже подтверждённые неопределённые попытки не запускаются снова.

В 1.8.3 поля страницы отзыва исключены из решения даже во время её загрузки. Если форма исчезает во время ответа модели, устаревшие ответы не применяются, тест возвращается в очередь, остальные материалы продолжаются. Кнопка «Возобновить задание» открывает уже сохранённый черновик без новой пересдачи; журнал отправок сохраняется. Варианты ответов передаются с обозначением курсива, жирного текста, верхних и нижних индексов — это сохраняет смысл, например, в обозначениях UML.

В 1.8.4 исправлена ложная отмена решения при обновлении подписанных ссылок на диаграммы. При сравнении формы не учитываются только параметры `expiry` и `hmac` у HTTPS-изображений доверенного прокси Coursera. Модели и загрузчику по-прежнему передаётся полная подписанная ссылка. Изменение файла, остальных параметров изображения, текста, вариантов или привязки картинки к вопросу блокирует применение устаревшего ответа и отправку.

В 1.8.5 готовый разбор с оценёнными вопросами закрывается через «Назад», если фоновая обложка всё ещё показывает ожидание результата без итоговой оценки. Бот читает актуальную оценку на обложке, затем продолжает пересдачи. При открытии разбора по известной оценке эта оценка сохраняется для чтения отзыва. Возврат выполняется один раз на посещение и учитывает незавершённую загрузку; «Стоп» отменяет ожидающее нажатие. Ранее отложенные пункты «Ожидает оценки» с адресом `view-feedback` проверяются однократно сразу после применения исправления. Журнал отправок сохраняется.

В 1.8.6 общий предел сохраняемого состояния увеличен с 64 000 до 256 000 символов JSON: разборы нескольких тестов должны помещаться вместе с очередью, материалами и журналом отправок. Предел одного разбора остаётся 32 000 символов; данные и журнал не обрезаются. Некорректная структура и состояние сверх общего предела отклоняются с сохранением последнего корректного сеанса. При превышении общего предела показывается отдельная причина.

После применения 1.8.6 отложенные проверки готовых отзывов выполняются ещё раз сразу; это восстанавливает очередь после сбоя сохранения 1.8.5. Повторная отправка уже записанной попытки остаётся запрещена.

В 1.8.7 открытая страница результата получает отдельное ожидание загрузки оценки до 60 секунд. Возраст старой отправки больше не закрывает это ожидание сразу после возврата из отзыва; новая загрузка документа обновляет время ожидания. Подтверждённый Chrome переход ожидается и дальше. Если оценка так и не появилась, тест остаётся в очереди без повторной отправки. Для цели 100% надписи «тест пройден» недостаточно без самой оценки. После применения ранее отложенные результаты отправленных тестов проверяются однократно сразу — как на обложках, так и на страницах отзыва.

В 1.8.8 медленная загрузка обложки больше не превращает тест в пропущенное задание. Бот ждёт подтверждённый браузером переход, затем при необходимости возвращает страницу в автоматическую очередь. Пустой элемент `form` сам по себе не считается письменным заданием; формы с редактором, загрузкой файла или текстом письменной работы по-прежнему пропускаются. Ранее ошибочно пропущенные обложки перепроверяются один раз.

Отсутствующая оценка или кнопка пересдачи, а также неудачный возврат из разбора больше не требуют ручного запуска проверки: бот продолжает материалы и возвращается позже. Для возврата используется известная ссылка на обложку из навигации курса, если она доступна. Старые пункты «Нужны данные» с этими конкретными причинами восстанавливаются однократно. Личные подтверждения, неуверенные ответы модели и неоднозначные намерения новой попытки не снимаются этой миграцией. Журнал отправок и ограничения количества попыток сохраняются.

Если чтение долго загружается и ещё не показало ни кнопку завершения, ни сообщение о блокировке, сеанс не выключается: бот ожидает подтверждённую загрузку браузера, затем при необходимости откладывает чтение и продолжает остальные пункты. Заблокированные решения peer-заданий остаются в ожидании.

Ожидание новой формы учитывает фактическую загрузку в Chrome. Если запуск попытки подтверждён, но форма ещё не появилась, бот проверит её позднее и продолжит другие материалы без повторного запуска этой попытки.

Порог сдачи вроде «не ниже 75%» не считается полученной оценкой. Если итоговую оценку прочитать нельзя, бот оставляет тест в очереди. При недоступных попытках он продолжает материалы и проверяет доступность позже с увеличением интервала. Ограничения Coursera сохраняются; достижение 100% может потребовать ожидания.

Журнал хранит каждую отправку отдельно. Новая отправка разрешается после распознавания новой редактируемой попытки; повторная отправка одной и той же попытки заблокирована. После 100% пересдачи прекращаются. Сохранённые ранее пройденные тесты один раз проверяются по новой цели; уже имеющие 100% не пересдаются. Если пункт выключен, достаточно успешной сдачи.

Смена адреса обложки на адрес попытки того же теста не отменяет решение. Если во время запроса действительно меняются вопросы, варианты или изображения, устаревшие ответы не применяются: тест возвращается в очередь и автоматически решается заново после загрузки. Другие материалы продолжаются; переход на другое задание отменяет запрос по-прежнему.

Всплывающий опрос Pendo об удобстве переводов исключён из распознавания тестов, полей ответов и кнопок отправки. Бот выбирает обложку или форму самого задания, не отвечает на опрос и не отправляет отзыв.

## Исправления 1.7.3

После заполнения ответов бот ждёт до 15 секунд, пока Coursera включит кнопку отправки. Пока форма обновляется, решатель повторно не вызывается и запись об отправке не создаётся. Если кнопка так и не стала доступной, тест остаётся в очереди «Нужны данные», а остальные материалы продолжаются.

## Исправления 1.7.2

При повторной проверке закрытого чтения бот распознаёт сообщение Coursera «Чтобы разблокировать, выполните предыдущее задание», сохраняет ожидание и продолжает очередь. Отсутствие кнопки завершения на такой странице больше не выключает весь сеанс.

Прозрачные PNG диаграмм приводятся к белому фону перед передачей модели, с точным сохранением видимых линий и подписей. Это исправляет чёрный прямоугольник вместо диаграммы UML. Поддерживаются обычные 8-битные RGBA/Gray+Alpha PNG без чересстрочной развёртки; неизвестный формат прозрачности остаётся в очереди для проверки.

Если модель неуверенно отвечает на длинный тест, помощник один раз повторяет анализ группами до пяти вопросов. Номера вопросов и привязки изображений сохраняются; ответы применяются только после проверки всего теста. Неуверенность небольшого блока показывает номера вопросов и недостающий контекст. Частичные ответы не отправляются. Повторный анализ ограничен временем и может расходовать больше лимита подписки.

## Очередь и модель

Очередь различает **Пропущено**, **Ожидает оценки**, **Заблокировано**, **Нужны данные** и **Не пройдено**. Если Codex временно недоступен, бот продолжает материалы и проверяет тест позже с увеличением интервала. Неопределённый результат отправки проверяется позднее без её повторения. Пересдачи выполняются только при включённой цели 100%; при выключенной цели неуспешный результат остаётся в очереди.

Неуверенный ответ модели больше не выключает весь сеанс: такой тест остаётся в **Нужны данные**, а доступные материалы и другие тесты продолжаются. Временные ошибки решателя и сетевые ошибки загрузки изображений проверяются автоматически позже. Ожидание блокировки сайтом не означает успешное прохождение: материалы, закрытые до выполнения отключённых peer-заданий, останутся недоступными.

Сеанс привязан к вкладке, курсу и доступному идентификатору аккаунта. При неопределённом аккаунте восстановление требует пункта **Продолжить сохранённую очередь этого аккаунта**. Одновременный запуск одного курса в разных вкладках запрещён. Закрытие браузера прекращает активный запуск; очередь сохраняется.

В 1.8.9 сохранённая запись закрытой вкладки больше не блокирует возобновление курса сообщением «Этот курс уже запущен в другой вкладке». Перед восстановлением расширение проверяет открытые вкладки Chrome и освобождает только подтверждённо закрытый сеанс. Журнал отправок и очередь сохраняются; работающая вкладка или ошибка проверки вкладок по-прежнему запрещают второй запуск.

Используется **gpt-6-sol**, `model_reasoning_effort="none"` — без расширенного рассуждения, для запрошенного режима Instant. Настройки обычного Codex не изменяются. Вопросы и варианты отправляются в облако через авторизованный Codex CLI; видео к модели не обращаются. Используются лимиты подписки ChatGPT. Мгновенная обработка тестов и правильность всех ответов не гарантируются.

Отдельная кнопка **Работа с тестом → Решить автоматически** только заполняет тест без отправки. Полный режим отправляет ответы и продолжает материалы. Ручной JSON-обмен, экспорт страниц, поиск ссылок на peer-работы и редакторные адаптеры убраны из интерфейса и загрузки страниц.

## Данные и установка

Посредник слушает только loopback-порт 43179 и проверяет токен. Native Messaging хранит приватное состояние в `%USERPROFILE%\.coursera-study-tools`, вне репозитория и OneDrive. Страница курса не получает токен. В локальном checkpoint Chrome сохраняются адреса, состояния, журнал попыток и разбор предыдущей попытки объёмом до 32 000 символов на тест. Разбор передаётся существующему облачному решателю только с соответствующим тестом и удаляется из checkpoint после достижения 100%. Подробности: [docs/native-connection.md](docs/native-connection.md).

Codex запускается без пользовательской конфигурации, инструментов управления компьютером и shell. Локальные модели не устанавливаются. Разрешения расширения сохранены для совместимости установленной копии; обработчики внешних лабораторных вкладок отключены.

## Разработка и проверка

Код расширения — обычный JavaScript, HTML и CSS. `course.js` управляет очередью, `content.js` читает тесты и материалы, `queue.js` содержит очередь. Старые адаптеры `assignments.js` и `editor-bridge.js` сохранены в исходниках, но не загружаются и не входят в дистрибутив. Совместимый посредник не получает от расширения задачи по программированию или письменным работам.

```powershell
npm test
npm run test:policy
npm run test:modern
npm run test:course
npm run test:perfect
npm run package
```

Playwright — только зависимость разработки. Проверки запускают отдельный Chromium с настоящим расширением, синтетическими страницами и тестовым решателем. Они не отправляют ответы в реальный аккаунт. `test:policy` проверяет исключение заданий, опцию подтверждения, поздний/скрытый флажок, запрет заполнения имени и сохранение настройки. В 1.7.1 исправления сопоставлены с реальными страницами Object Oriented Design: русская обложка обзора модуля, 30 вопросов и 7 изображений заключительного экзамена. Полное прохождение этого реального курса не заявляется: end-to-end проверка использует синтетический курс с одной кнопкой запуска, временным отказом модели, перезагрузкой и автоматическим возвратом к тесту.

Упаковщик создаёт **dist/coursera-study-tools.zip** и распакованную папку **dist/coursera-study-tools**. После распаковки выбирайте вложенную папку **extension**. Проект не связан с Coursera и не одобрен ею.
